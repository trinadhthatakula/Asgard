# Asgard 2.1.1

Configured navigation bars and rails animate destination bounds, label visibility and captions
using the host Material motion scheme. Automatic captions use each appearance's geometry and the
widest destination label, keeping their placement stable when switching tabs. Shared press feedback
uses updated scale settings without replacing its interaction collector.

Progress rings clamp animated samples when drawing and exposing accessibility progress, including
overshooting custom springs. Animation sampling moves out of composition, and drawing geometry is
cached. Shimmer caches its gradient and translates it during drawing; native pixel checks cover
animation phases, color changes, resizing and recovery from zero width.

The Android gallery aligns Lifecycle at 2.11.0 so both previously skipped lint detectors run.
Warnings now fail lint. A separate optimized, profileable benchmark variant and reusable replay
tools cover nine component workloads; CI compiles and lints that variant alongside the gallery.

See the [performance report](../performance-2.1.1.md) for emulator measurements, raw evidence,
audit coverage and deferred work, and the [Lifecycle validation](../lifecycle-lint.md) for detector
verification. Emulator timing does not establish physical-device performance.

Validation includes 31 Android host tests, 32 native Android interaction/rendering tests,
15 Python tooling tests, retained JVM entry-point compatibility, Android/WebAssembly compilation,
web gallery distribution and clean debug/release/benchmark lint.

Merging the version bump to `main` triggers the existing Maven Central publication workflow.
Consumers such as Thor can update their dependency after the 2.1.1 artifacts become available.
