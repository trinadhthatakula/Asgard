# Asgard 2.2.0

Add `com.trinadhthatakula:asgard-glass:2.2.0` for per-component frosted glass. Register a backdrop with `Modifier.asgardGlassSource` and select individual controls with `Modifier.asgardGlass`, `AsgardGlassSurface`, or a toolbar/navigation container. Hardware-accelerated Android API 33+ and browser Wasm render frost. Android API 28–32, software-rendered Android windows and reduced-transparency mode use a solid fill. [Integration guide](../glass-ui.md)

The Android and browser galleries offer independent previews on all 54 entries. The Asgard skill includes integration guidance and a compatibility score for each of the 44 public components. [Component ratings](../../.claude/skills/asgard-ui/references/glass.md)

## Audit fixes

- Opted-in glass surfaces now keep a solid base even when the caller supplies a translucent color and backdrop sampling is unavailable. Explicitly deselecting glass restores the caller’s Material fill.
- Calendar heatmaps observe in-place updates to Compose state lists, including changes to already selected dates.
- Line charts omit samples with non-finite coordinates and handle large finite ranges. Stacked bars derive their scale from drawable values, preserve caller alpha when dimming, and handle totals above the maximum finite Float. Timeline bars support the full range of ordered Long timestamps.
- The Pages deployment includes the standalone HTML report and refreshes the gallery's release label after Maven publication creates the tag.

## Verification

The two regressions involving glass fallback and live heatmap updates failed before their fixes and passed afterward. The API 36 emulator ran the full 38-test Android suite. The API 28 emulator ran all four glass tests. The local checks included 33 Android host tests, 19 Python tests, all three app lint variants and the optimized benchmark APK.

Core and glass were packaged into an isolated Maven repository. A separate Gradle project compiled the glass modifier, custom surface, toolbar and navigation integrations against those artifacts for Android and Wasm. Core metadata contains no Haze dependency. The Xiaomi gallery smoke test exercised an interactive glass tile. Optimized frame times on physical hardware and in browsers remain unmeasured.
